# AWK Lab

## Overview

In this lab, I worked with AWK to process, filter, and analyze structured data using the Linux command line.

The purpose of this lab was to practice working with records and fields, using patterns and conditions to extract specific information, and performing calculations on data stored in text files.

## What I Worked On

- Working with records and fields using `$0`, `$1`, `$2`, and other field variables
- Changing field separators using `-F`
- Searching for specific records using patterns and conditions
- Using `substr()` to extract characters from fields
- Using `split()` to separate names into an array
- Using `length()` to count characters
- Working with comparison and logical operators
- Using `NR` to display record numbers
- Calculating totals and averages from numeric fields
- Modifying field values while processing records
- Creating and executing an AWK script with multiple operations
