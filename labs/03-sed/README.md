# SED Lab

## Overview

In this lab, I worked with SED to search, modify, and filter text using the Linux command line.

The purpose of this lab was to practice using SED commands and regular expressions to work with text files, including replacing text, deleting lines, printing specific results, and creating a SED script to perform multiple operations.

## What I Worked On

- Searching and replacing text using the `s` command
- Printing specific lines using `-n` and `p`
- Deleting lines using `d`
- Working with line numbers and address ranges
- Using regular expressions to match specific patterns
- Using `^` and `$` to identify the beginning and end of lines
- Inserting and appending text using `i` and `a`
- Creating and running a SED script using the `-f` option
