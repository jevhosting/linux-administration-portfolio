# Server Setup Lab

## Overview

In this lab, I installed and configured two Linux virtual machines, Ubuntu Server and CentOS Stream 10, using QEMU/KVM and Virtual Machine Manager on Fedora Linux.

The purpose of this lab was to practice installing Linux servers, configuring virtual machines, verifying network connectivity, and managing servers remotely.

## Lab Environment

- **Host OS:** Fedora Linux 44 (KDE Plasma)
- **Virtualization:** QEMU/KVM, libvirt, and virt-manager
- **Guest Systems:** Ubuntu Server and CentOS Stream 10
- **Networking:** NAT

## What I Worked On

- Installed and configured Ubuntu Server and CentOS Stream 10
- Configured virtual machine resources, including CPU, RAM, and storage
- Verified network interfaces and IP addresses using `ip -br addr`
- Tested network connectivity using `ping`
- Connected to both servers remotely using SSH
- Transferred files between systems using SCP
