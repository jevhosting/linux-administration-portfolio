# GREP Lab

## Overview

In this lab, I worked with GREP to search for specific text and patterns inside files using the Linux command line.

The purpose of this lab was to practice using GREP with different options and regular expressions to find, filter, and display information from a text file.

## What I Worked On

- Searching for specific words and characters in a file
- Using `^` and `$` to match the beginning and end of a line
- Using `-v` to exclude lines containing certain patterns
- Working with bracket expressions like `[0-9]`, `[A-Z]`, and `[a-z]`
- Using `-E` for extended regular expressions
- Matching patterns with repetition using `{2,3}`
- Using `|` as an OR operator
- Combining GREP commands with pipes to filter results
